# PeaversSplits

Calls out how far ahead or behind the published pace your Mythic+ run is, at
every boss, **while the key is still running**.

A **split** is the time from the start of a run to a boss dying. The dungeon
timer is one deadline at the very end and tells you nothing until it is too late
to act on it; being ninety seconds down at the second boss is knowable at the
second boss.

```
Kystia Manaheart down at 8:17, +0:31 vs pace, inside the usual range.
```

A live bar tracks the gap against the next boss continuously, so you watch it
open rather than hearing about it once the boss is down.

Requires [PeaversSplitsData](https://github.com/peavers-warcraft/PeaversSplitsData)
for the benchmark, which is generated daily from [parses.gg](https://parses.gg).

See the [README](https://github.com/peavers-warcraft/PeaversSplits#readme).
